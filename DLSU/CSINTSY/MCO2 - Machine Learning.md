# Code Switching

**Code Switching** - two or more languages for proficiency-driven and deficiency-driven
**proficiency-driven** - best express in english or language
**deficiency-driven** we know a particular word is best express in another language but we dont know the equivalent in it in English so we code-switch to Filipino
